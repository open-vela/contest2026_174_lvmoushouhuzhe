# 演示视频分镜脚本（≤5 分钟）

作品：ESP32-P4 OpenVela 显示与视觉链路适配（新硬件适配赛道）
目标：功能演示 + 交互操作 + AI 能力展示，三条要求都覆盖。

---

## 镜头 1｜开场（0:00–0:30）

- **画面**：开发板 ESP32-P4-Function-EV-Board 特写，镜头缓慢拉远展示整板
- **字幕**：「ESP32-P4 OpenVela 新硬件平台适配」
- **旁白**：本项目在乐鑫 ESP32-P4（双核 RISC-V 400MHz）上移植 OpenVela，打通 MIPI-DSI 显示与 MIPI-CSI 摄像头两条链路，实现 30fps 零拷贝预览。

---

## 镜头 2｜开机自检（0:30–1:00）

- **画面**：板子重新上电，屏幕瞬间变**纯红**（这是显示链路自检信号）
- **画面切换**：串口终端滚动 boot 日志，特写 `PSRAM init OK, size=33554432`、`SPI SRAM memory test OK`
- **旁白**：纯红屏代表 DSI PHY→Host→Bridge→DMA→面板全链路打通；串口可见 32MB PSRAM 初始化成功。

---

## 镜头 3｜设备节点（1:00–1:30）

- **画面**：NSH 终端输入 `ls /dev`
- **特写**：`/dev/fb0`（显示，双缓冲）、`/dev/video0`（摄像头）两个节点
- **旁白**：fb0 是 1024×600 RGB565 双缓冲 framebuffer；video0 是 V4L2 摄像头设备，SC2336 I2C 探测（chip ID 0xcb3a）通过。

---

## 镜头 4｜30fps 零拷贝预览（1:30–3:00，核心）

- **画面**：NSH 输入 `campreview 180`，屏幕立即出现**摄像头实时预览**
- **画面切换**：串口滚动 `campreview: 60 frames, 29.7 fps` → `120 frames, 30.0 fps` → `180 frames, 30.0 fps`
- **特写字幕**：「zero-copy · 30fps」
- **旁白**：摄像头 DMA 直接写显示缓冲，零 CPU 拷贝，稳定 30fps。相比逐像素转换（6fps）和 memcpy（15fps），提升约 5 倍。

---

## 镜头 5｜交互操作（3:00–4:00）

- **画面**：NSH 命令行交互演示
  - `campreview -h`（查看用法）
  - `campreview 60`（跑 60 帧，约 2 秒自动退出）
  - `ls /dev`（再次确认设备）
- **旁白**：所有功能通过 NSH 命令交互，参数可控，适合自动化测试。

---

## 镜头 6｜AI 能力展示（4:00–4:30）

- **画面**：NSH 输入 `campilot -h`，显示「campilot once / campilot text」用法
- **旁白**：campilot 应用封装了 MiMo 大模型 API（HTTP Bearer 鉴权，POST /v1/chat/completions），支持文本/图像多模态查询。受板载网络环境限制，云端链路在演示中未完全调通，但代码已就绪（如实际网络可用可现场演示）。

---

## 镜头 7｜结尾总结（4:30–5:00）

- **画面**：回到开发板全景，屏幕停留预览画面
- **字幕**：「新硬件适配 · 显示 + 摄像头 · 30fps 零拷贝」
- **旁白**：本项目展示了 openvela 在 RISC-V 高端多媒体 SoC 上的落地能力，感谢观看。

---

## 录制建议

- 全程串口终端 + 摄像头预览双画面（画中画），或分屏
- 串口工具用 minicom（`minicom -D /dev/ttyACM1 -b 115200`），或用 DTR 支持的终端
- 实拍开发板时确保屏幕内容清晰（避免反光）
- 时长控制在 4 分 30 秒左右留余量
